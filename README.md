# Viblio — Android MVP

Локальная библиотека видео с плейлистами и вертикальным просмотром.

## Сборка
GitHub Actions автоматически собирает debug APK при каждом push в main. Запустить вручную можно во вкладке Actions → Build Viblio APK → Run workflow.

После успешной сборки открой запуск workflow и скачай артефакт Viblio-debug-apk.

## Возможности MVP
- Плейлисты и создание новых плейлистов.
- Локальное сохранение списка ссылок.
- Добавление ссылки вручную и через Android Share.
- Вертикальный просмотр внутри плейлиста.
- Воспроизведение прямых MP4/M3U8 ссылок через Media3.
- Загрузка прямых URL через Android DownloadManager.

## Ограничение TikTok
Обычная ссылка vm.tiktok.com или tiktok.com/@.../video/... не является прямой ссылкой на видеофайл. MVP сохраняет такую ссылку, но не извлекает и не обходит защиту TikTok. Для встроенного воспроизведения и загрузки нужен прямой URL на файл или разрешённый источник/экспорт.

## Технологии
Kotlin, Jetpack Compose, AndroidX Media3, Gradle.
